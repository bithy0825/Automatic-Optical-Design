# 损失 × 可训练参数：作用力矩阵与权重/学习率推荐

> 数据来源：`tests/measure_loss_forces.py`（内置专用配置与死亡矩阵，可替换成你的系统复测）。
> 测试系统：3 非球面 + 3 训练间隔 + 传感器（P=8），强曲率分布、中间面出射到空气，
> 使各类死亡自然发生；不依赖 `demo/config.toml`。

## 定义

对某损失列（权=1，其余权=0）：

- **力(p)** = 逐元素 `|∂L/∂p|` 均值（全系统同名叶子参数聚合）；
- **单位损失力** = 力(p) / L0，L0 为该损失的逐个体均值。
  梯度随权重线性缩放，因此它**精确等于**"该损失加权值为 1 时贡献给参数 p 的梯度"——
  注意：这是**缩放**（`w = 1/L0`）而非**赋值**；常数 1.0 没有计算图，
  损失值恒 0 的列（无死亡事件）不存在可缩放的对象，只能构造死亡状态来测（见下）。
- **行归一化** = 每行（参数）各列单位损失力 ÷ 行合计，单元格 = `比例 (原始单位损失力)`。

bounds 列逐元件按其**自身** bounds 上界外推 1 个单位测量；铰链解析律：
**逐越界元素力 = 2/越界量**（越界 1 单位时 = 2），表内为同名元素平均。

mask 与材料编号不可微（GA 专属），不在表内。

## 为什么有些 toll 列会全 0

不是梯度通路断了，而是**事件没有发生**。toll 是"按死因平均的死亡代价"：没有任何光线
死于某死因时，`toll × (cause == 该死因)` 逐元素恒 0——损失恒 0，且在一个邻域内局部恒零
（死因翻转是离散事件），`1/L0` 缩放无从谈起。它的梯度只由死亡光线携带，所以必须构造
有死光的状态（状态 C）才测得到。对照两表：

- 状态 A 里 `sag_domain` / `solver_negative` 死亡数为 0 → 两列全 0；
- 状态 C 强制出 216 / 297 条死光 → 两列立即出现非零力（sag_domain 拉 curvature 1.42，
  solver_negative 拉 thickness 0.0107）。

这也是 toll/bounds 的共性：**事件驱动，触发时主导、消失时自动归零**（自带退火）。

## Diameter 的梯度来源（为什么不只是 bounds）

Diameter 实际有三条梯度路径，前两条是设计使然：

1. **aperture_clip 的 toll（设计）**：孔径裁决分两层——`hold = r² ≤ R²` 是布尔截断
   （无梯度），但 `toll = R² − r²` 是**可微的死亡深度**；`Verdict.at` 里的 `torch.where`
   只*选择*哪个站点的 toll 存活，被选中的值保留完整梯度链。被剪光线的死亡深度对
   D 的导数为 −D/2，梯度下降会**增大** D 以"复活"边缘被剪光线（表中 0.00546 实测）。
   这不是 bug，是"罚死亡深度、驱动参数自救"的机制。

   关键误区：`torch.where(cond, a, b)` **对 a、b 是可微的**（分段线性选择：
   `∂out/∂a = cond`，`∂out/∂b = ¬cond`），不可微的只有条件 `cond` 本身。数值实证
   （r=11 被 R=10 的孔径剪死）：`hold=False, toll=21, D.grad=-10`——梯度穿过 where
   精确到达 D，方向为增大口径。
2. **非球面归一化（结构）**：`Asphere.sag()` 的归一化半径 `ρ = Diameter/2`，
   sag 本身依赖 D，因此 effl/spot 对 D 有（很小的）直接梯度。
   纯 sphere/conic 系统无此路径，effl/spot 对 D 精确为 0。
3. **bounds 铰链（护栏）**：越界时按 2/越界量 回拉（表中 0.0833）。

另外注意 `sag_domain` 对 Diameter **精确为 0**：sag 域判定来自圆锥基底的
`1 − (1+κ)c²r²`，不含归一化半径 ρ。

## 死亡复活实证

死亡损失的梯度不仅在数值上存在，还真能把光线拉回存活（`tests/test_resurrection.py`）：
死亡矩阵状态 → **仅用 toll 损失** Adam 80 步（lr 用下节推荐值）：

| 死因 | 优化前死光 | 80 步后 | 结果 |
|---|---|---|---|
| sag_domain | 216 | **0** | 全部复活 |
| aperture_clip | 226 | **0** | 全部复活（口径被梯度推大） |
| tir | 154 | **0** | 全部复活 |
| solver_negative | 297 | 7 | 98% 复活 |
| solver_convergence | 14 | 11 | 部分复活 |
| **存活** | 1469/2376 | **2358/2376** | toll 损失 7.36 → 0.019 |

残余的 18 条是**深死/病态**个体：gradient 修复"边缘死亡"（死亡深度浅、方向连续）；
跨界的病态个体（如构造的 α=0.3）需要大步长离散跳跃——那正是 GA 变异的职责，
两阶段分工由此而来。

## 读表结论

1. **solver_convergence 的单位力是全场最高的**（curvature 24~47）：不收敛光线的残差
   对曲率极度敏感。它的 L0 极小（0.007~0.01），实际贡献 = 单位力 × L0，通常温和；
   若你的系统大量不收敛，应先查物理（面形/初值/迭代数），而不是调权重。
2. **solver_negative 是 thickness 的专属通道**：负距离直接由间隔决定（0.0107），
   对 curvature 只有间接影响（0.289）。
3. **sag_domain 拉 curvature（1.42）与 kappa（0.0331）**，对 diameter 恒 0。
4. **tir 主要拉 curvature**（7.03）——临界角由入射角（几何）与折射率（GA 材料）决定。
5. **curvature 是所有追迹损失的主战场**；thickness/kappa 对追迹损失的直接敏感度
   低 1~3 个数量级，几何贡献间接。
6. **alpha 可被梯度精修**（spot 单位力 0.0086~0.010，convergence 时 2.69）。

## 权重（loss weights）推荐

权重决定的是**危机时刻的优先级**（toll/bounds 只在违约时非零），稳态几何精修由
effl/spot 承担：

| 权重 | 推荐值 | 理由 |
|---|---|---|
| `spot` | **1.0**（锚） | 主几何项 |
| `effl` | **0.5 ~ 1.0** | 对 curvature 的单位力 ≈ spot 的 60~80%，L0 小，取 1.0 也不喧宾夺主 |
| `toll:*` | **1.0** | 死亡修复是硬约束，触发时应主导；精修被死亡项拖走时降到 0.3~0.5 |
| `bounds:*` | **1.0** | 单位力（0.083）远小于追迹项（~1~7），只负责拉回界内；GA 频繁越界时升到 5~10 |

经验公式：想让损失 L 对参数 p 的拉力达到 spot 的水平，设 `w_L = spot单位力(p) / L单位力(p)`。

## 学习率（lr）推荐

**Adam 的实际步长 ≈ lr，与梯度大小基本无关**（动量归一化），所以 lr 应按**参数的
物理步长尺度**设，而不是按力表设。参照系：各参数的 mutate std 就是物理尺度。

| 参数 | 典型量级 | 推荐 lr | 说明 |
|---|---|---|---|
| curvature | ~1e-1 | **5e-4 ~ 1e-3** | 主力参数，200 步 × 1e-3 ≈ 覆盖常用值域 |
| thickness | ~5 | **5e-2 ~ 1e-1** | ⚠️ default_lr=1e-3 时 200 步只走 0.2，相对值域 [1,20] 几乎爬不动 |
| diameter | ~20 | **1e-2 ~ 5e-2** | 主要受 bounds / aperture toll 约束，大步长无妨 |
| kappa | ~1 | **1e-3 ~ 1e-2** | 梯度小不代表该小步——Adam 不看梯度大小 |
| alpha | ~1e-4 | **1e-5 ~ 1e-4** | ⚠️ 用 default_lr=1e-3 会一步走过头几个数量级——必须单独配小 lr |

配置示例（`lr` 表按叶子名匹配）：

```toml
[[optimizer]]
type = "adam"
step = 200
default_lr = 1e-3
lr = { thickness = 0.05, diameter = 0.02, kappa = 0.005, alpha = 1e-4 }
```

`grad_norm = 10` 在死亡事件多的阶段频繁触发，起稳定作用；死亡消失后可放宽到 50。

## 局限与复测

- 数值依赖测试状态：toll 各列只在对应死亡发生时非零。复测你的系统：
  编辑 `tests/measure_loss_forces.py` 顶部的 `CONFIG` 与 `apply_death_matrix` 后运行。
- 力按"逐元素 |grad| 均值"聚合；个体间分布不均时，GA 阶段的逐个体差异比表中均值更大。
- SGD 用户的步长 ∝ 力表本身：curvature 会天然主导，需按力表反比配 lr；
  Adam 用户用上节的物理尺度法即可。
